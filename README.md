# RAG-Based PDF Chatbot

A chatbot that allows users to upload PDF documents and ask questions about their content.

## Technologies Used
- Python
- Streamlit
- LangChain
- Sentence Transformers
- FAISS
- PyPDF

## Features
- PDF Upload
- Text Extraction
- Text Chunking
- Embedding Generation
- Vector Search using FAISS
- Semantic Retrieval
